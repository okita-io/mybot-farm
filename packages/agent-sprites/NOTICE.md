# Attribution

`agent-sprites` ports the seeded pixel-sprite-generator algorithm. No native
canvas is used; PNG bytes are encoded with `pngjs`.

algorithm.

## mixel

MIT License

TypeScript rewrite of pixel-sprite-generator. This port follows mixel's seeded
RNG and tintable output, without depending on `seedrandom` or a DOM canvas.
